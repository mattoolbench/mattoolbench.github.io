Scoring notes评分说明
Score = normalized task score (0–100) averaged across all tasks in the domain.  SR = success rate: fraction of tasks where all sub-criteria are satisfied.  GUI and Origin tasks use vision-based evaluation; Code tasks use exact key-value matching (MP, OQMD) or file-existence checks (OPTIMADE, Pymatgen).  OPTIMADE uses score_by_attempts: (max_steps − first_success_step + 1) / max_steps.  Steps* = mean steps on successful episodes only.  FTR = false termination rate (agent ends without completing the task). Score = 任务归一化得分（0–100），取该领域所有任务的平均值。  SR = 成功率：所有子评判标准均满足的任务比例。  GUI 和 Origin 任务采用基于视觉的评测；Code 任务使用精确键值匹配（MP、OQMD）或文件存在性检查（OPTIMADE、Pymatgen）。  OPTIMADE 采用 score_by_attempts：(max_steps − 首次成功步骤 + 1) / max_steps。  步数* = 仅成功回合的平均步数。  FTR = 错误终止率（智能体未完成任务即终止）。
